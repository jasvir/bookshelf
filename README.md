# The Unfinished Library

An infinite, zoomable library inspired by [Colin Thompson](https://en.wikipedia.org/wiki/Colin_Thompson_(writer)). Wander through colorful, winding shelves full of books with punning titles, and zoom in to find little quirky toys, tiny inhabitants, and hidden curiosities. Follow doorways into more libraries, with new things to discover at every turn.

If you're running Chrome and Gemini Nano is available, you can look inside some books for the start of the story that no one else has dreamt of so far!
